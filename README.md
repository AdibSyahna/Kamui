# Kamui

Kamui is a Discord bot that combines LLM-powered chat capabilities with moderation features. It functions as both a conversational AI assistant and a content moderator, providing intelligent responses to user messages while filtering out spam and phishing attempts.

## Features
Most features are in alpha stage, which means lots of bugs + changes are to be expected.

- **LLM Chat Responses**: Responds to messages in channels using configured LLM
- **Channel-Specific Settings**: Toggle LLM responses per channel with admin controls
- **Web Search Tool**: Integrates Brave Search API for web-based information retrieval
- **Memory Management**: Maintains conversation history per channel using MongoDB
- **Context Overflow Handling**: Manages conversation length with summarization strategies
- **Response Gating**: Filters and validates LLM responses before sending to Discord
- [DISABLED] **JavaScript Execution Tool**: Can execute JavaScript code in a sandboxed environment
- [OUTDATED] **Phishing/Spam Detection**: Filters out spam links and malicious content

## Planned Features

- **Honeytrap Channel**: Add and watch honeytrap channels to handle spam accounts.
- **Music Player**: Play music from external source to Discord Voice Channel.
- **AI Live Speak**: Directly talk to AI in Discord Voice Channel.

## Architecture

Kamui is built using:
- Discord.js for Discord API integration
- MongoDB for persistent data storage (conversations, settings)
- LangChain for LLM integration and tool support
- TypeScript for type safety and maintainability

## Installation

1. Clone the repository
2. Install dependencies: `npm install`
3. Rename all `*.example.*` files and remove the `.example` name at the middle, and update their content with your desired configuration
4. Start the bot: `npm run start`

## LLM Tools

Kamui supports custom LLM tools that extend its capabilities:

1. **Web Search Tool**: Performs web searches using Brave Search API
2. **Run JavaScript Tool**: Executes JavaScript code in a sandboxed environment
